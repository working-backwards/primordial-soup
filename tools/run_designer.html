Primordial Soup — Run Designer

Design one simulation run in the three-layer vocabulary, then download the YAML and execute it with python scripts/run_design.py <file>. Only five things are required: a name, a title, an environment family, a policy preset, and world seeds. Everything else has a working default.

Environmental conditions

The world the organization operates in — everything fixed for a run that no participant controls. For most runs, choose a family and leave the rest alone.

Initiative pool family

Latent variables (set by the experimenter, hidden from governance)

Each initiative has a true quality and a true duration that governance never observes. You choose the family, which fixes the distributions these are drawn from; the world seed then resolves the actual values before the simulation starts. Governance only ever sees noisy signals and the beliefs learned from them — that hidden gap between belief and truth is what the study measures governance against. There are no controls in this panel by design: if you need different distributions, that is a new environment family (add it in src/primordial_soup/presets.py).

Time horizon — baseline: 313 weeks (≈ 6 years)

Changing the horizon changes how much time patient governance has to observe completions of long initiatives. Only override when deliberately testing a different horizon.

Operating policy

How governance actually decides week to week: when to stop initiatives, what belief level is required to start work, how the desired portfolio mix leans. Select one named preset — the parameter values below are shown for reference and come directly from src/primordial_soup/presets.py.

Why there are no sliders here: individually editing stop thresholds or patience windows would require knowing how all the parameters interact — exactly the low-level config assembly problem this designer exists to avoid. Systematic policy variation is what the campaign sweep machinery (campaign.py) is for. If you need a fourth posture, add a named preset in src/primordial_soup/presets.py and it becomes available to every YAML.
